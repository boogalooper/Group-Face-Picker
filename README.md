# Group Face Picker for Photoshop

Group Face Picker помогает быстро заменить лицо ребёнка на групповой фотографии фрагментом из другого дубля той же группы.

Рабочий процесс простой: вы открываете групповую фотографию в Photoshop, выделяете лицо нужного ребёнка, запускаете скрипт и выбираете подходящий дубль по превью. Скрипт находит того же ребёнка на соседних фотографиях и вставляет фрагмент в текущее выделение.

По умолчанию вставка выполняется **без поворота и без масштабирования**: положение донора выравнивается по глазам, а размер области остаётся равным исходному выделению Photoshop. При необходимости можно отдельно включить **подгонку масштаба лица** — это единственная дополнительная трансформация; поворот по-прежнему не используется.

---

# Что умеет программа

- находит выбранного ребёнка на других групповых фотографиях;
- показывает отдельные превью найденного лица;
- отмечает рекомендацию подписью «ЛУЧШИЙ» без зелёной рамки;
- выделяет только выбранное превью синей рамкой; при открытии выбирает рекомендованный кадр, а без рекомендации — первый;
- позволяет выбирать кадры стрелками ← → ↑ ↓ и вставлять выбранное нажатием Enter или двойным кликом;
- показывает степень сходства прямо под каждым превью;
- отмечает превью текущего открытого файла;
- по умолчанию вставляет выбранный фрагмент в Photoshop в масштабе 1:1;
- опционально подгоняет только масштаб лица по двум независимым пропорциям лица, без поворота;
- поддерживает обычное прямоугольное выделение и Quick Mask;
- создаёт маску слоя по исходному выделению;
- поддерживает JPEG, TIFF, PSD и распространённые RAW-файлы;
- сохраняет анализ группы в кэш, чтобы повторный выбор другого ребёнка был значительно быстрее;
- при необходимости умеет находить границы текущей группы внутри большой папки;
- может использовать NVIDIA GPU или работать только на CPU;
- Python и CUDA-библиотеки устанавливаются в собственное окружение программы — системный Python не требуется.
- по желанию собирает подтверждённые пользовательские предпочтения лиц для будущего персонального ранжирования.

# Требования к компьютеру

## Операционная система

Программа предназначена для **64-битной Windows**.

Рекомендуется:

- Windows 10 x64;
- Windows 11 x64.

Python-сервер и установщик рассчитаны именно на Windows. macOS в текущей версии не поддерживается.

---

## Adobe Photoshop

Нужен настольный Adobe Photoshop для Windows с поддержкой обычных JSX / ExtendScript-скриптов.

Для RAW-файлов дополнительно используется Adobe Camera Raw, который открывается самим Photoshop.

Точная минимальная версия Photoshop в программе не зафиксирована. Рекомендуется использовать современную поддерживаемую Adobe версию Photoshop.

---

## Процессор

Программа может полностью работать **без видеокарты NVIDIA**, используя CPU.

Минимально достаточно современного 64-битного процессора. Для комфортной обработки групповых фотографий рекомендуется процессор примерно с **6 и более потоками**.

Параллельный анализ файлов настраивается отдельно и использует до 4 потоков анализа.

---

## Оперативная память

Рекомендуется:

- **16 ГБ RAM** — нормальная работа с обычными JPEG и небольшими группами;
- **32 ГБ RAM** — предпочтительно для 40–60 МП фотографий, больших групп, PSD и RAW;
- больше 32 ГБ полезно, если одновременно открыт тяжёлый Photoshop-документ и обрабатываются большие исходники.

Программа не хранит в памяти индексы всех просмотренных папок. В RAM остаются модель распознавания и текущая группа; предыдущие группы сохраняются на диск в кэш.

---

# Видеокарта

## Видеокарта не обязательна

Group Face Picker может работать в режиме **CPU**. NVIDIA GPU нужна только для ускорения распознавания лиц.

AMD и Intel GPU в текущей версии для ускорения InsightFace не используются.

---

## Какие NVIDIA поддерживаются

Текущая GPU-сборка использует:

```text
ONNX Runtime GPU 1.26.0
CUDA 12.8
cuDNN 9.24
```

Для этого стека официально поддерживаются NVIDIA архитектуры **Turing и новее**.

Для обычных GeForce это означает:

```text
GTX 16xx        — поддерживается
RTX 20xx        — поддерживается
RTX 30xx        — поддерживается
RTX 40xx        — поддерживается
RTX 50xx        — поддерживается
```

Старые поколения:

```text
GTX 10xx / Pascal   — GPU-режим текущей сборки не рекомендуется
GTX 9xx / Maxwell   — GPU-режим текущей сборки не рекомендуется
```

На таких компьютерах используйте режим **CPU**.

---

## Драйвер NVIDIA

Для GPU-режима нужен достаточно новый драйвер NVIDIA.

Практический минимум для текущего CUDA 12.x стека:

- GTX 16xx / RTX 20xx / RTX 30xx / RTX 40xx — драйвер примерно **528.33 или новее**;
- RTX 50xx / Blackwell — драйвер **570.65 или новее**.

Рекомендуется не ориентироваться на минимальную цифру, а установить актуальный **NVIDIA Studio Driver** или свежий Game Ready Driver.

Для RTX 50xx особенно важно использовать новый драйвер: установщик специально закрепляет CUDA 12.8 и cuDNN 9.24 с поддержкой Blackwell.

---

## Видеопамять

Модель не требует огромного объёма VRAM.

Практически:

- 4 ГБ VRAM обычно достаточно;
- 6–8 ГБ и больше дают хороший запас.

Большой размер исходной фотографии в первую очередь влияет также на обычную RAM, потому что декодирование изображения выполняется до распознавания.

# Что устанавливает install.bat

Программа использует собственное окружение и не зависит от системного Python.

Устанавливаются:

- приватный **CPython 3.11.16 x64**;
- собственный `runtime\venv`;
- InsightFace `buffalo_l`;
- ONNX Runtime;
- зависимости для JPEG / TIFF / PSD / RAW;
- при обнаружении NVIDIA — приватные CUDA 12.8 / cuDNN-библиотеки внутри окружения программы.

Отдельно устанавливать Python, CUDA Toolkit или cuDNN обычно **не требуется**.

## Лицензия модели InsightFace

Код InsightFace распространяется отдельно от предобученных моделей. Используемый Group Face Picker пакет `buffalo_l` относится к открытым моделям InsightFace, для которых официальный проект указывает некоммерческое исследовательское использование; для коммерческого применения требуется отдельная лицензия на модель. Актуальные условия проверяйте в официальном репозитории InsightFace и на сайте проекта.

При первой установке нужен интернет.

Оставьте на системном или рабочем диске несколько гигабайт свободного места. Для установки с NVIDIA GPU разумно иметь **около 8–10 ГБ свободного пространства с запасом**.

# Быстрый старт

## 1. Установка

1. Распакуйте программу в отдельную папку.
2. Запустите `install.bat`.
3. Выберите:

```text
1 — Normal secure mode
```

4. Дождитесь сообщения `Installation complete`.

Если установка прерывается из-за HTTPS-проверки антивирусом или Kaspersky, повторите установку и выберите режим совместимости:

```text
2 — Kaspersky compatibility mode
```

Системный Python устанавливать не нужно.

---

## 2. Первый запуск сервера

После установки один раз запустите:

```text
run_server.bat
```

Оставьте окно сервера открытым.

После первого успешного соединения JSX запоминает путь к `run_server.bat`. При следующих запусках, если локальный сервер не отвечает, Photoshop попробует запустить его автоматически.

### Отмена через Esc

Во время системного progress-bar Photoshop можно нажать **Esc**. Group Face Picker прекращает текущий JSX-этап и, если на Python-сервере уже выполняется анализ/применение настроек, отправляет серверу запрос отмены. Сервер перестаёт запускать новые кадры и следующие этапы. Уже начатый нативный вызов InsightFace/ONNX для одного кадра может завершиться прежде, чем worker остановится.

Если `Esc` нажат во время ожидания сервера, JSX прекращает ожидание. Запущенный вручную сервер продолжает работать.

Запомненный путь хранится в настройках Photoshop:

```text
app.preferencesFolder\gfp_client_state.json
```

---

## 3. Запуск JSX

Запустите в Photoshop:

```text
Group Face Picker.jsx
```

Его можно запускать через **File → Scripts → Browse...** или установить в обычную папку Photoshop Scripts.

После поиска дублей окно превью может тонкой зелёной рамкой подсветить **один рекомендованный кадр**. Источник подсветки выбирается в настройках: `Отключено`, `Публичная FBP`, `Моя обученная модель` или `Публичная FBP + моя модель`. Подсветка ничего не вставляет автоматически — это только визуальная рекомендация для быстрой оценки.

### Быстрый доступ к настройкам

Если при запуске `Group Face Picker.jsx` удерживать **Shift**, скрипт сразу откроет окно настроек и не будет запускать поиск лица/вставку в этом запуске.

Клиентская копия настроек Photoshop хранится отдельно от рабочего конфига Python-сервера:

```text
app.preferencesFolder\gfp_client_config.json
```

Рабочие серверные параметры сохраняются Python-сервером в `gfp_config.json` рядом с `group_face_server.py`. Поэтому больше нет двух активных файлов с одинаковым именем, которые могли бы разойтись после переноса JSX в `Photoshop\Presets\Scripts`.

При первом запуске, если `gfp_client_config.json` ещё отсутствует, JSX автоматически ищет прежние настройки в безопасном порядке: пользовательский `gfp_config.json` в `app.preferencesFolder`, рабочий конфиг рядом с ранее запомненным `run_server.bat`, затем файл рядом с JSX. Найденные значения копируются в `gfp_client_config.json`. После успешной миграции старые клиентские файлы остаются нетронутыми и больше не участвуют в обычном чтении настроек Photoshop.

### Photoshop Actions

Скрипт зарегистрирован как собственное Script Event с постоянным UUID и после запуска записывает служебный boolean-параметр в playback parameters Photoshop. Благодаря этому запуск корректно записывается и отображается в палитре **Actions / Экшены**. Служебный параметр не изменяет настройки Group Face Picker и не влияет на поиск или вставку.

# Как пользоваться

## 1. Откройте групповую фотографию

Файл должен существовать на диске. Несохранённый новый документ без исходного файла использовать нельзя.

---

## 2. Выделите лицо ребёнка

Можно использовать:

- прямоугольное выделение;
- Quick Mask для более сложной формы.

Выделение должно охватывать лицо выбранного ребёнка достаточно однозначно.

---

## 3. Запустите Group Face Picker.jsx

Скрипт передаст серверу путь к открытому файлу и координаты выделения.

Если для этой группы ещё нет актуального кэша, начнётся анализ фотографий.

---

## 4. Выберите подходящий дубль

После анализа появится окно с лицами того же ребёнка.

- текущий открытый файл помечается **ТЕКУЩИЙ**;
- наведите курсор на превью, чтобы увидеть имя файла и степень сходства;
- один клик выбирает превью;
- второй быстрый клик вставляет его;
- также можно нажать **Вставить выбранное**.

Текущий файл показывается как ориентир, но вставить его в самого себя нельзя.

## Сбор статистики для обучения

Галочка **«Собирать статистику для обучения»** находится **только в окне настроек JSX**. В окне выбора лиц отдельного переключателя нет. По умолчанию сбор выключен; после явного включения настройка сохраняется на стороне Photoshop и действует для последующих вставок. Python-сервер не хранит отдельную копию этого флага, поэтому состояние интерфейса и фактическая запись статистики не могут разойтись.

Если галочка включена, данные записываются **только после полностью успешной вставки** в Photoshop. Отмена окна, выбор текущего кадра или ошибка/откат вставки ничего не добавляют в датасет.

Одно действие по-прежнему сохраняет базовое pairwise-предпочтение:

```text
выбранное лицо > текущее лицо
```

Если при открытии окна был автоматически выбран кадр «ЛУЧШИЙ», а вы одним кликом выбрали другой кадр и вставили его, событие дополнительно запоминает отвергнутую рекомендацию. При обучении это даёт ещё одну надёжную пару:

```text
выбранное вами лицо > отвергнутая рекомендация
```

Никаких дополнительных действий для этого не требуется. Если рекомендация была принята без изменения, отдельная новая пара из неё не создаётся. Остальные показанные кандидаты автоматически проигравшими **не считаются**, потому что пользователь мог не сравнивать каждый из них внимательно.

Формат остаётся `schema_version = 1`: старые события и уже накопленный датасет не требуют преобразования. Новый обучатель использует старые `chosen > current` как раньше и автоматически добавляет дополнительную пару только там, где новое событие содержит явное отклонение рекомендации.

Данные находятся рядом с Python-сервером:

```text
training_data/
  events/   JSON-события выбора
  faces/    320×320 face-crop в JPEG
```

Face-crop называются SHA-256 хэшем содержимого, поэтому одинаковое изображение не хранится повторно. События имеют уникальные и идемпотентные ID. В JSON не сохраняется абсолютный путь к фотографии — только имя исходного файла и служебные параметры выбора. При первом запуске конкретного экземпляра создаётся локальный `training_data/collector.json` со случайным UUID; имя компьютера и имя пользователя в него не записываются, а при объединении этот файл не импортируется.

### Объединение данных с нескольких компьютеров

Скопируйте целиком папки `training_data` с других экземпляров Group Face Picker и запустите, например:

```text
merge_training_data.bat "D:\PC1\training_data" "E:\PC2\training_data"
```

Можно передать и корневую папку другого экземпляра Group Face Picker — утилита сама найдёт внутри `training_data`. Объединение проверяет SHA-256 face-crop, копирует только недостающие файлы и дедуплицирует уже импортированные события. Повторно объединять тот же набор безопасно.

### Обучение персональной модели

Для обучения добавлен файл:

```text
train_personal_model.bat
```

Он использует накопленные pairwise-события `chosen > current` и, для новых событий, дополнительные пары `chosen > rejected recommendation`, если вы заменили автоматически предложенный кадр. Старый датасет полностью совместим и продолжает использоваться без миграции. Основная идея: готовый **MobileNetV3-Small** используется как замороженный visual encoder, а обучается только небольшая ranking-head. Поэтому для первой рабочей модели не требуется переобучать большую нейросеть с нуля.

#### Рекомендуемый порядок работы

1. На каждом компьютере включите **Настройки → Собирать статистику для обучения**. По умолчанию галочка выключена.
2. Работайте как обычно. Статистика появляется только после успешной замены лица.
3. Периодически скопируйте `training_data` с остальных компьютеров на основной компьютер.
4. Объедините их, например:

```bat
merge_training_data.bat "D:\PC1\training_data" "E:\PC2\training_data"
```

5. После объединения запустите:

```bat
train_personal_model.bat
```

6. Первый запуск создаст отдельное окружение:

```text
runtime/training_venv/
```

и установит туда PyTorch/torchvision и зависимости обучения. Рабочее окружение сервера `runtime/venv` при этом не изменяется. Для первого запуска нужен интернет. Вес предобученного backbone torchvision сохраняется локально под `models/torch/`.

7. После обучения результат появится в:

```text
personal_model/
  personal_preference.onnx
  personal_preference.json
  training_report.md
```

`training_report.md` содержит количество событий, размер train/validation, способ разделения и точность на отложенных парах.

#### Сколько данных нужно

Обучатель технически разрешает запуск от **20 уникальных непротиворечивых пар**, но это только проверка пайплайна. Практический ориентир:

```text
< 100 пар       — экспериментальная модель, продолжать собирать данные
300–800         — уже имеет смысл сравнивать с публичным FBP
1000–3000       — хороший объём для персональной ranking-head
3000+           — можно отдельно рассматривать более глубокое дообучение
```

Это не жёсткие математические границы. Главное число — **validation pair accuracy** в `training_report.md`: доля отложенных реальных pairwise-выборов, где модель правильно предсказала ваше предпочтение. Для старого датасета это `chosen > current`; новые записи могут дополнительно содержать `chosen > rejected recommendation`.

#### Защита от плохих данных

Перед обучением скрипт:

- проверяет SHA-256 каждого сохранённого face-crop;
- удаляет из обучающей выборки точные повторы одной и той же пары;
- обнаруживает противоречие `A > B` и `B > A` и исключает такую пару целиком;
- по возможности разделяет train/validation так, чтобы одно и то же лицо-crop не встречалось с обеих сторон;
- сообщает в отчёте, если строгий split без пересечения лиц оказался невозможен.

#### Что именно получается на выходе

`personal_preference.onnx` принимает RGB face-crop `224×224` и выдаёт число `0..1`:

```text
больше значение = кадр ближе к вашим накопленным предпочтениям
```

Это **не универсальная оценка красоты человека**. Модель предназначена прежде всего для сравнения дублей одного и того же человека.

Group Face Picker **подключает `personal_preference.onnx` автоматически**, если файл находится в папке `personal_model/` рядом с `group_face_server.py` и в настройках выбран режим `Моя обученная модель` или `Публичная FBP + моя модель`.

Текущая версия Photo Select AI пока **не подключает этот ONNX автоматически**. Не заменяйте им вручную публичный FBP. Подключение `personal_preference.onnx` и смешивание его с публичным FBP для Photo Select AI должно быть сделано отдельным обновлением после того, как накопится достаточно статистики и validation покажет полезный результат.

#### Дополнительные параметры обучения

Обычный запуск не требует параметров. При необходимости BAT передаёт аргументы Python-обучателю, например:

```bat
train_personal_model.bat --min-pairs 100 --validation 0.20 --device cpu
```

Доступные полезные параметры:

```text
--data PATH        другая папка training_data
--output PATH      другая папка для готовой модели
--min-pairs N      минимальное число уникальных пар
--validation 0.20  доля validation
--device auto      auto / cpu / cuda
--epochs N         максимальное число эпох ranking-head
```

Обычно рекомендуется оставить значения по умолчанию.

# Как выполняется вставка

По умолчанию Group Face Picker работает в исходном режиме 1:1:

- поворот не применяется;
- масштабирование не применяется;
- размер исходного фрагмента равен размеру выделения;
- положение совмещается по глазам;
- после вставки создаётся маска слоя по исходному выделению.

## Подгонка масштаба лица

В окне выбора дубля есть оперативная галочка **«Подгонять масштаб лица»**. Её можно быстро включать и выключать непосредственно перед вставкой; заходить в общие настройки не нужно. Последнее состояние запоминается для следующего окна выбора.

Изменение этой настройки применяется сразу к уже открытому набору превью: повторно выбирать ребёнка или перезапускать сервер не требуется.

Размер оценивается преимущественно по расстоянию между глазами. Второй замер вносит небольшую поправку, которая уменьшается при расхождении пропорций и полностью исключается при сильном расхождении. Сравниваются:

- расстояние между глазами;
- расстояние от линии глаз до линии рта.

После этого донорский фрагмент **равномерно** масштабируется одним коэффициентом. Поворота, перспективной трансформации и деформации нет. Положение после масштабирования по-прежнему привязывается к глазам.

Если для уменьшения лица нужен более крупный исходный фрагмент, программа заранее берёт область большего размера и затем уменьшает её. Если лицо нужно увеличить — берётся меньшая область и увеличивается. Благодаря этому итоговая маска полностью перекрывает исходное выделение Photoshop.

Для Quick Mask сохраняется фактическая непрямоугольная форма маски.

# RAW и Adobe Camera Raw

RAW анализируются иначе, чем обычные JPEG.

Для быстрого поиска лиц Python использует встроенное превью RAW. Это намного быстрее, чем полностью проявлять каждый RAW.

Когда пользователь выбирает донор, Photoshop открывает уже **оригинальный RAW через Camera Raw**.

Размер встроенного RAW-preview и размер документа после Camera Raw могут отличаться. Поэтому координаты лица хранятся в нормализованном виде и пересчитываются уже после того, как Photoshop реально открыл донор.

Размер итогового фрагмента при этом всё равно остаётся равным исходному выделению Photoshop.

---

## XMP и настройки Camera Raw

Отдельных настроек XMP в интерфейсе нет.

Если активный RAW открыт с настройками Camera Raw, Group Face Picker старается применить тот же базовый набор Camera Raw Settings к другим RAW текущей группы.

Программа умеет использовать:

- обычный sidecar `<имя файла>.xmp`;
- XMP, доступный из уже открытого документа Photoshop, в том числе встроенные метаданные некоторых форматов, например DNG.

Для других RAW создаются только **недостающие** sidecar `.xmp`.

Существующий sidecar другого файла не перезаписывается.

# Одна группа или несколько групп в папке

В настройках есть опция:

**Поиск границ группы**

По умолчанию она **выключена**.

---

## Если в папке только одна группа

Оставьте поиск границ выключенным.

Тогда все поддерживаемые файлы папки считаются одной группой и могут анализироваться параллельно.

Это самый быстрый режим.

---

## Если в папке подряд лежат разные группы

Включите **Поиск границ группы**.

Тогда открытый файл становится точкой отсчёта, а сервер идёт от него назад и вперёд и сравнивает состав лиц.

После уверенной смены состава анализ в этом направлении прекращается. Другие группы глубже по папке не должны анализироваться.

Для подтверждения границы могут быть проверены 1–2 первых кадра соседней группы, но они не включаются в кэш текущей группы.

Поиск границ немного медленнее обычного режима, поэтому включать его для папки с одной группой нет необходимости.

# Кэш

Первый анализ группы — самый долгий.

Во время него сохраняются:

- embeddings найденных лиц;
- координаты лиц и глаз;
- небольшие JPEG-превью каждого лица;
- маленькие готовые превью для интерфейса.

Поэтому при выборе следующего ребёнка из той же группы программе уже не нужно заново читать каждый 20–60 МП JPEG / PSD / RAW только ради окна превью.

Кэш находится в:

```text
runtime\cache
```

По умолчанию срок жизни кэша — **48 часов с момента последнего использования**.

---

## Работа с большим количеством групп

Сервер не держит в RAM все группы, которые вы обработали за день.

В оперативной памяти находится только текущий индекс группы. При переходе к другой группе предыдущий индекс освобождается, а его дисковый кэш остаётся до TTL.

Поэтому последовательная обработка 50 и более разных групп не должна приводить к линейному росту памяти от старых индексов.

### Публичная FBP и личная модель

`install.bat` теперь скачивает не только InsightFace `buffalo_l`, но и публичную модель портретных предпочтений (`HowCuteAmI / SCUT-FBP5500`).

Чтобы использовать собственную обученную модель в Group Face Picker:

1. включите в настройках Photoshop галочку **Собирать статистику для обучения**;
2. поработайте в обычном режиме и накопите пары `chosen > current`;
3. при необходимости объедините данные с других компьютеров через `merge_training_data.bat`;
4. запустите `train_personal_model.bat`;
5. убедитесь, что появились файлы:

```text
personal_model/
  personal_preference.onnx
  personal_preference.json
  training_report.md
```

6. откройте настройки Group Face Picker и выберите режим **Моя обученная модель** или **Публичная FBP + моя модель**.

Если личная модель отсутствует или не загрузилась, Group Face Picker не прекращает работу: подсветка просто станет недоступной или автоматически откатится к публичной FBP в комбинированном режиме.

## Жизненный цикл модели распознавания лиц

InsightFace `buffalo_l` загружается **один раз на процесс Python-сервера** и остаётся в памяти между поисками разных детей и групп. Изменение только размера detector (`640/800/1024`) теперь перенастраивает уже загруженный SCRFD **без повторной загрузки ArcFace/ONNX-сессий**. Полная перестройка FaceEngine нужна только при реальной смене CPU ↔ GPU или при единственном аварийном переходе CUDA → CPU. Переключение public/personal FBP, открытие окна настроек и обычные новые запросы InsightFace не перезагружают.

---

## Режим вычислений

### Авто

Рекомендуемый режим.

Если CUDA GPU доступен и успешно запускается — используется NVIDIA. Если GPU недоступен, сервер переходит на CPU.

### GPU

Требует рабочий `CUDAExecutionProvider`.

Если NVIDIA / драйвер / CUDA-окружение не подходят, сервер выдаст ошибку вместо скрытого перехода на CPU.

### CPU

Принудительно использует процессор.

Полезно для компьютеров без подходящей NVIDIA или для диагностики проблем GPU.

# Скорость / мелкие лица

Доступны три размера детектора:

```text
Быстро — 640
Баланс — 800
Точно — 1024
```

Важно: это **не размер отдельного лица**.

Это размер входного изображения, в котором детектор ищет лица по всему групповому кадру.

### 640

Быстрее всего. Хорошо подходит для не слишком больших групп и достаточно крупных лиц.

### 800

Хороший компромисс между скоростью и поиском маленьких лиц.

### 1024

Медленнее, но маленькие лица получают больше пикселей на этапе детекции.

Полезно для больших групп, когда дети занимают небольшую часть кадра.

Изменение 640 / 800 / 1024 применяется к работающему серверу сразу.

## Как теперь обрабатываются 40–60 МП файлы

Детектор лиц не получает полный 40–60 МП кадр. Перед SCRFD создаётся только уменьшенная копия размером, соответствующим выбранному профилю `640 / 800 / 1024`.

Для JPEG используется уменьшение непосредственно при декодировании, поэтому программе обычно не нужно сначала разворачивать весь JPEG в огромный RGB-массив. Для PNG / TIFF / PSD экономия зависит от формата и способа хранения изображения, но полный кадр всё равно больше не копируется в NumPy и затем ещё раз в BGR только ради детектора.

После детекции координаты лиц и глаз пересчитываются обратно в координаты исходного изображения. ArcFace распознаёт человека не по уменьшенному кадру целиком, а по небольшому участку вокруг каждого найденного лица. Поэтому геометрия вставки в Photoshop остаётся в исходных пикселях.

Для JPEG распознавание дополнительно может использовать аппаратно поддерживаемое декодером уменьшение `1/2`, `1/4` или `1/8`, но только если после него у самого маленького найденного лица остаётся достаточно пикселей для ArcFace. Это уменьшает расход RAM и время декодирования без изменения размера итогового фрагмента.

# Локальный и сетевой сервер

Обычно Photoshop и Python-сервер работают на одном компьютере.

Можно запустить Python-часть на другом компьютере в локальной сети и подключить Photoshop к его IP-адресу.

В этом случае:

- сервер должен слушать сетевой адрес;
- Windows Firewall должен разрешать соединение на выбранный порт;
- Photoshop должен видеть этот компьютер по сети.

Текущий сетевой протокол не выполняет аутентификацию клиентов. Поэтому открывайте порт только в доверенной локальной сети и не публикуйте его напрямую в интернет. Для обычного локального режима `127.0.0.1` это ограничение не создаёт дополнительного сетевого доступа.

Автоматический запуск `run_server.bat` предназначен прежде всего для локального сервера. Обычный путь вида `C:\...\run_server.bat` на другом компьютере нельзя удалённо выполнить только потому, что сервер сообщил этот путь.

---

# Автоматический запуск сервера

После первого успешного соединения Photoshop запоминает путь к `run_server.bat`.

Если при следующем запуске ping не отвечает, JSX:

1. проверяет сохранённый путь;
2. пытается запустить BAT через Windows;
3. ждёт появления Python API;
4. только если запуск не удался — показывает ошибку и предлагает запустить сервер вручную.

Если папку программы перенесли, один раз запустите новый `run_server.bat` вручную, чтобы Photoshop запомнил новый путь.

---

# Безопасность исходных файлов

Group Face Picker не удаляет исходные фотографии.

При обычной вставке донор:

- открывается в Photoshop;
- временно обрезается до нужного фрагмента;
- слой переносится в целевой документ;
- если файл был открыт скриптом — закрывается без сохранения;
- если донор был открыт пользователем заранее — его состояние истории восстанавливается.

Исходный файл на диске не должен изменяться.

Для RAW отдельно могут создаваться отсутствующие `.xmp` с Camera Raw Settings, как описано выше.

# Перенос программы

Папку Group Face Picker можно перенести или переименовать.

`run_server.bat` при запуске проверяет приватное Python-окружение и при необходимости исправляет пути виртуального окружения после перемещения папки.

Если окружение отсутствует или повреждено, запустите:

```text
install.bat
```

После переноса рекомендуется один раз вручную запустить новый `run_server.bat`, чтобы Photoshop запомнил его новый путь.

# Если GPU не работает

Сначала попробуйте в настройках:

```text
Режим вычислений: Авто
```

Если программа работает на CPU, а CUDA не активируется:

1. обновите драйвер NVIDIA;
2. убедитесь, что видеокарта не старее Turing / GTX 16xx;
3. снова запустите `install.bat`, чтобы восстановить приватные CUDA-библиотеки;
4. перезапустите `run_server.bat`;
5. проверьте журнал сервера.

Для RTX 50xx особенно проверьте, что драйвер не старее 570.65.

# Если сервер не запускается

Проверьте, что установка была завершена успешно и существует:

Затем запустите вручную:

```text
run_server.bat
```

Если окружение повреждено — повторите `install.bat`.


# Главное

Обычный рабочий процесс выглядит так:

1. один раз установить программу через `install.bat`;
2. запустить `run_server.bat`;
3. открыть групповую фотографию в Photoshop;
4. выделить лицо ребёнка;
5. запустить `Group Face Picker.jsx`;
6. выбрать подходящий дубль;
7. вставить его в текущее выделение.

Если в папке находится только одна группа, оставьте **Поиск границ группы выключенным**.

Если подряд лежит несколько разных групп — включите поиск границ.

Для большинства компьютеров хорошая отправная точка — **Авто + Баланс 800**. Если маленькие лица теряются, используйте **1024**; если важнее скорость — **640**.


## Подключение при запуске

Запустите `run_server.bat` вручную и оставьте окно открытым. JSX ожидает ответ до двух минут и не запускает дополнительный сервер. Ожидание можно отменить клавишей Esc. При первом анализе загрузка вычислительных компонентов и обработка опорного кадра могут занять заметное время; в окне прогресса отображается время анализа.


## Точность совмещения

В обоих режимах совмещается середина глаз с компенсацией округления вырезки. Обычный режим сохраняет масштаб 1:1; дробный сдвиг может потребовать интерполяции пикселей Photoshop. При включённой подгонке масштаб рассчитывается преимущественно по расстоянию между глазами. Расстояние от глаз до рта вносит небольшую поправку только при согласованности замеров. Поворот и неравномерное растяжение не применяются. Небольшой запас вокруг вырезки скрывается исходной маской выделения.


Для открытия настроек запустите JSX с зажатым Shift. Проверки фотографии и выделения в этом режиме не выполняются. Если открытых документов нет, скрипт открывает настройки и без Shift.
